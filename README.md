# Top Speed Arabic Enhanced

نسخة مطوّرة ومُعَرَّبة من لعبة السباق الصوتية **Top Speed 3.0.4**، مبنية على السورس المفتوح الأصلي من Playing in the Dark.

## بيانات النسخة

- اسم اللعبة: **Top Speed Arabic Enhanced**
- المطوّر/صاحب التعديلات: **أحمد سامي**
- نوع اللعب: فردي ضد الكمبيوتر + لعب جماعي محلي/شبكي وأونلاين
- المنصة الحالية: Windows
- الترخيص: GNU GPL v3

> تنبيه حقوقي: الكود الأصلي وحقوقه محفوظة لأصحابه الأصليين Playing in the Dark. اسم أحمد سامي يشير إلى تطوير هذه النسخة والتعديلات المضافة، وليس إلى تأليف الكود الأصلي.

## المزايا الموجودة في السورس

- سباق صوتي مناسب للمكفوفين.
- لعب فردي ضد منافسين بالكمبيوتر.
- Time Trial وSingle Race وStreet Adventure.
- دعم السيارات والحلبات المخصّصة.
- دعم الصوت ثلاثي الأبعاد وأصوات المحرك والفرامل والاصطدام.
- دعم أذرع التحكم وعجلة القيادة وForce Feedback.
- دعم اللعب الجماعي والاتصال الشبكي الموجود في السورس الأصلي، بما في ذلك الاستضافة والانضمام والبحث عن الخوادم.
- اختيار عدد اللفات والمنافسين ومستوى الصعوبة.

## التعديلات والتحسينات في هذه النسخة

- إعادة تنظيم المشروع كإصدار مستقل باسم Top Speed Arabic Enhanced.
- الاحتفاظ باللعب الجماعي والأونلاين وعدم إخفائهما من القائمة الرئيسية.
- إضافة ملف توثيق عربي لخطة التعريب والتطوير.
- إعداد هيكل واضح لإضافة ملفات الصوت العربية في `installer/tspeed/Sounds/ar/`.
- توثيق نظام ملفات السيارات `.vhc` لإضافة سيارات جديدة وتعديل السرعة والتسارع والتوجيه وعدد الغيارات.
- تجهيز خطة لإضافة نظام ترقيات ونيترو وحفظ تقدم، مع عدم الادعاء بأن هذه الأنظمة مكتملة قبل تنفيذها واختبارها.

## البناء

المشروع قديم ويحتاج بيئة Windows متوافقة مع:

- Microsoft Visual Studio 2008 أو إصدار أحدث يدعم مشاريع Visual C++ القديمة.
- DirectX SDK August 2007، مع DirectPlay.
- مكتبات libogg وlibvorbis وlibvorbisfile الثابتة.

راجع [تعليمات البناء الأصلية](README.md) وملف [ARABIC_OFFLINE_EDITION.md](ARABIC_OFFLINE_EDITION.md) للتفاصيل الحالية.

للبناء التلقائي على GitHub راجع [BUILD-WINDOWS.md](BUILD-WINDOWS.md). ولخطة السيارات والمناطق والبيئات الجديدة راجع [EXPANSION_CONTENT.md](EXPANSION_CONTENT.md).

## الصوت العربي

واجهة اللعبة تعتمد بدرجة كبيرة على ملفات صوتية منطوقة. لإضافة العربية، تُنشأ ملفات WAV أو OGG بنفس أسماء ومسارات ملفات اللغة الإنجليزية داخل:

```text
installer/tspeed/Sounds/ar/
```

ويجب تسجيل الصوت العربي الطبيعي أو توفيره من مصدر مرخّص، مع اختبار كل رسالة داخل اللعبة.

## لا أملك Visual Studio

لا تحتاج إلى شراء نسخة مدفوعة. على Windows يمكنك استخدام **Visual Studio Community** مجانًا في حالات الاستخدام الفردي والمشاريع المفتوحة المصدر، أو استخدام **Visual Studio Build Tools** المجانية من Microsoft. هذا المشروع قديم، لذلك قد تحتاج إلى تثبيت مكوّنات C++ القديمة وDirectX SDK August 2007 ومكتبات OGG/Vorbis.

المستودع يحتوي على السورس وليس ملف EXE جاهزًا. تحويله إلى EXE يحتاج بيئة بناء Windows واختبارًا حقيقيًا؛ لذلك لا ينبغي اعتبار وجود السورس دليلًا على وجود نسخة تشغيل جاهزة. بعد نجاح البناء يمكن نشر ملف EXE مع السورس وملف GPLv3 وفق الشروط السابقة.

## حالة المستودع

المستودع عام Public حتى يستطيع أي شخص قراءة السورس وتنزيله. خيار اللعب الجماعي والأونلاين موجود في القائمة، لأن هذه النسخة تحتفظ بأنظمة DirectPlay الأصلية. أما التعريب الصوتي الكامل، ونظام النيترو، والمتجر، والترقيات، وحفظ التقدم، فهي مراحل تطوير تحتاج تنفيذًا واختبارًا قبل وصفها بأنها مكتملة.

## موارد التوسعة من EchoDrive

تمت إضافة حزمة الصوتيات CC0 الموثقة من مستودع EchoDrive المملوك لأحمد سامي داخل `installer/tspeed/ExpansionAudio/`. كما أضيفت كتالوجات نصية للقوائم والرسائل والمركبات والمناطق داخل `installer/tspeed/Locales/`. الكتالوجات الحالية تدعم العربية والإنجليزية والفرنسية واليابانية والصينية، بينما التسجيلات الصوتية لهذه اللغات مؤجلة كما هو محدد في خطة المشروع.

يتضمن فهرس المناطق خمس مدن إضافية هي أبوظبي وجدة وطوكيو وباريس وكيب تاون، إلى جانب المدن الخمس الأولى، كما يتضمن بيانات المحافظات المصرية للتوسعة إلى 27 منطقة. راجع [EXPANSION_CONTENT.md](EXPANSION_CONTENT.md) و[REUSE_POLICY.md](REUSE_POLICY.md) لمعرفة ما تم نقله وترخيصه وما يحتاج إلى ربط برمجي داخل اللعبة القديمة.

تم تعديل Workflow البناء ليحاول تثبيت DirectX SDK الرسمي وبناء OGG/Vorbis تلقائيًا قبل ترجمة المشروع. نجاح البناء النهائي ما زال يحتاج اختبارًا على Windows لأن مشروع DirectPlay قديم وقد يتطلب إصلاحات توافق إضافية.
